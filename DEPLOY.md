# Deployment checklist

1. Deploy the full contents of this folder to the portfolio repository.
2. Keep `rubelhosen.com` in `CNAME`.
3. Confirm GitHub Pages serves `https://rubelhosen.com/`.
4. Make sure any old `rhosen.github.io` portfolio URL does not compete as a separate canonical page.
5. Confirm LinkedIn and GitHub both link to `https://rubelhosen.com/`.
6. In Google Search Console:
   - verify `rubelhosen.com`
   - submit `https://rubelhosen.com/sitemap.xml`
   - inspect the homepage
   - request indexing after deployment
7. Test desktop and mobile navigation.
8. Test reduced-motion mode.
9. Run Lighthouse on the deployed URL.
10. Validate the JSON-LD / structured data after deployment.
